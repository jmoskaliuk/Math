# Codex Briefing

Dieses Repository enthält die Startarchitektur für ein Moodle-Mathetrainer-System mit getrenntem Curriculum-Plugin.

Bei Erweiterungen beachten:
- Moodle Coding Style
- Klare Trennung zwischen Activity- und Local-Plugin
- Keine vollständigen Lehrplantexte übernehmen
- Datenschutzvorgaben einhalten
